# Keyboard Shortcuts for Windows (VS Code)

This cheat sheet lists useful shortcuts for coding and testing.

## 1) File and Window

| Action | Shortcut |
|---|---|
| New file | Ctrl+N |
| New window | Ctrl+Shift+N |
| Open file | Ctrl+O |
| Open folder | Ctrl+K Ctrl+O |
| Save | Ctrl+S |
| Save all | Ctrl+K S |
| Close editor | Ctrl+W |
| Close window | Ctrl+Shift+W |
| Reopen closed editor | Ctrl+Shift+T |

## 2) Command Palette and Quick Open

| Action | Shortcut |
|---|---|
| Command Palette | Ctrl+Shift+P |
| Quick Open (files) | Ctrl+P |
| Go to symbol in file | Ctrl+Shift+O |
| Go to symbol in workspace | Ctrl+T |
| Open recent | Ctrl+R |

## 3) Basic Editing

| Action | Shortcut |
|---|---|
| Undo | Ctrl+Z |
| Redo | Ctrl+Y |
| Cut line/selection | Ctrl+X |
| Copy line/selection | Ctrl+C |
| Paste | Ctrl+V |
| Select all | Ctrl+A |
| Delete line | Ctrl+Shift+K |
| Move line up | Alt+Up |
| Move line down | Alt+Down |
| Copy line up | Alt+Shift+Up |
| Copy line down | Alt+Shift+Down |
| Insert line below | Ctrl+Enter |
| Insert line above | Ctrl+Shift+Enter |
| Indent line | Ctrl+] |
| Outdent line | Ctrl+[ |
| Toggle line comment | Ctrl+/ |
| Toggle block comment | Shift+Alt+A |

## 4) Multi-Cursor and Selection

| Action | Shortcut |
|---|---|
| Insert cursor above | Ctrl+Alt+Up |
| Insert cursor below | Ctrl+Alt+Down |
| Add cursor at click | Alt+Click |
| Add next matching selection | Ctrl+D |
| Select all matches | Ctrl+Shift+L |
| Expand selection | Shift+Alt+Right |
| Shrink selection | Shift+Alt+Left |
| Column (box) selection | Shift+Alt+Drag |

## 5) Navigation

| Action | Shortcut |
|---|---|
| Go to line | Ctrl+G |
| Go to definition | F12 |
| Peek definition | Alt+F12 |
| Go to references | Shift+F12 |
| Go back | Alt+Left |
| Go forward | Alt+Right |
| Next editor tab | Ctrl+Tab |
| Previous editor tab | Ctrl+Shift+Tab |
| Switch editor group (1,2,3) | Ctrl+1/2/3 |

## 6) Search and Replace

| Action | Shortcut |
|---|---|
| Find | Ctrl+F |
| Replace | Ctrl+H |
| Find next | F3 |
| Find previous | Shift+F3 |
| Find in files | Ctrl+Shift+F |
| Replace in files | Ctrl+Shift+H |
| Toggle regex in search | Alt+R |
| Toggle case sensitive | Alt+C |
| Toggle whole word | Alt+W |
