# Keyboard Shortcuts for macOS (VS Code)

This cheat sheet lists useful shortcuts for coding and testing.

## 1) File and Window

| Action | Shortcut |
|---|---|
| New file | Cmd+N |
| New window | Cmd+Shift+N |
| Open file | Cmd+O |
| Open folder | Cmd+K Cmd+O |
| Save | Cmd+S |
| Save all | Option+Cmd+S |
| Close editor | Cmd+W |
| Close window | Cmd+Shift+W |
| Reopen closed editor | Cmd+Shift+T |

## 2) Command Palette and Quick Open

| Action | Shortcut |
|---|---|
| Command Palette | Cmd+Shift+P |
| Quick Open (files) | Cmd+P |
| Go to symbol in file | Cmd+Shift+O |
| Go to symbol in workspace | Cmd+T |
| Open recent | Ctrl+R |

## 3) Basic Editing

| Action | Shortcut |
|---|---|
| Undo | Cmd+Z |
| Redo | Cmd+Shift+Z |
| Cut line/selection | Cmd+X |
| Copy line/selection | Cmd+C |
| Paste | Cmd+V |
| Select all | Cmd+A |
| Delete line | Cmd+Shift+K |
| Move line up | Option+Up |
| Move line down | Option+Down |
| Copy line up | Option+Shift+Up |
| Copy line down | Option+Shift+Down |
| Insert line below | Cmd+Enter |
| Insert line above | Cmd+Shift+Enter |
| Indent line | Cmd+] |
| Outdent line | Cmd+[ |
| Toggle line comment | Cmd+/ |
| Toggle block comment | Option+Shift+A |

## 4) Multi-Cursor and Selection

| Action | Shortcut |
|---|---|
| Insert cursor above | Option+Cmd+Up |
| Insert cursor below | Option+Cmd+Down |
| Add cursor at click | Option+Click |
| Add next matching selection | Cmd+D |
| Select all matches | Cmd+Shift+L |
| Expand selection | Shift+Option+Right |
| Shrink selection | Shift+Option+Left |
| Column (box) selection | Shift+Option+Drag |

## 5) Navigation

| Action | Shortcut |
|---|---|
| Go to line | Ctrl+G |
| Go to definition | F12 |
| Peek definition | Option+F12 |
| Go to references | Shift+F12 |
| Go back | Ctrl+- |
| Go forward | Ctrl+Shift+- |
| Next editor tab | Ctrl+Tab |
| Previous editor tab | Ctrl+Shift+Tab |
| Switch editor group (1,2,3) | Cmd+1/2/3 |

## 6) Search and Replace

| Action | Shortcut |
|---|---|
| Find | Cmd+F |
| Replace | Option+Cmd+F |
| Find next | Cmd+G |
| Find previous | Shift+Cmd+G |
| Find in files | Cmd+Shift+F |
| Replace in files | Cmd+Shift+H |
| Toggle regex in search | Option+Cmd+R |
| Toggle case sensitive | Option+Cmd+C |
| Toggle whole word | Option+Cmd+W |

## 7) Folding and Code Actions

| Action | Shortcut |
|---|---|
| Fold region | Option+Cmd+[ |
| Unfold region | Option+Cmd+] |
| Fold all | Cmd+K Cmd+0 |
| Unfold all | Cmd+K Cmd+J |
| Quick fix / code actions | Cmd+. |
| Rename symbol | F2 |
| Format document | Shift+Option+F |
| Format selection | Cmd+K Cmd+F |

## 8) Terminal (Integrated)

| Action | Shortcut |
|---|---|
| Toggle terminal | Ctrl+` |
| New terminal | Ctrl+Shift+` |
| Kill terminal | Cmd+W (terminal focus) |
| Clear terminal | Cmd+K |
| Split terminal | Cmd+\\ |

## 9) Debugging

| Action | Shortcut |
|---|---|
| Start/Continue | F5 |
| Stop | Shift+F5 |
| Restart | Shift+Cmd+F5 |
| Step over | F10 |
| Step into | F11 |
| Step out | Shift+F11 |
| Toggle breakpoint | F9 |

## 10) OS-Level Text Editing

| Action | Shortcut |
|---|---|
| Jump by word | Option+Left/Right |
| Select by word | Option+Shift+Left/Right |
| Go to line start/end | Cmd+Left/Right |
| Select to line start/end | Shift+Cmd+Left/Right |
| Delete previous word | Option+Backspace |
| Delete next word | Fn+Option+Delete |

## 11) Browser Shortcuts (Playwright)

| Action | Shortcut |
|---|---|
| New tab | Cmd+T |
| Reopen closed tab | Cmd+Shift+T |
| Next tab | Ctrl+Tab |
| Previous tab | Ctrl+Shift+Tab |
| Refresh page | Cmd+R |
| Hard refresh | Cmd+Shift+R |
| Open DevTools | Option+Cmd+I |

## 12) JavaScript Comment Shortcuts

| Action | Shortcut |
|---|---|
| Toggle single-line comment (`//`) | Cmd+/ |
| Toggle block comment (`/* ... */`) | Option+Shift+A |

## Notes

- Some shortcuts vary by keyboard layout and extensions.
- On Mac laptops, you might need `Fn` with F5/F10/F11.
